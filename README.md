# FLIPTECH — Construction Web Solutions

Англоязычный сайт Alexander Push для продажи веб-разработки строительным компаниям США. Самостоятельный Next.js App Router проект для размещения на Vercel или Node.js хостинге.

## Быстрый запуск

Node.js 22 или новее.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000. Основной маршрут — `/construction-websites`; `/` показывает тот же лендинг с canonical на основной маршрут.

## Production

1. В `.env.local` укажите `NEXT_PUBLIC_SITE_URL` — свой HTTPS-домен без завершающего слеша. Пока адрес не указан, поисковая индексация отключена. Не оставляйте учебный адрес из `.env.example` при публикации.
2. Укажите свои реальные контакты в `NEXT_PUBLIC_CONTACT_EMAIL` и `NEXT_PUBLIC_LINKEDIN_URL`. Пустые контакты скрыты.
3. Создайте PostgreSQL базу (например, Neon), укажите `DATABASE_URL`. Нужна SSL-связь. Этот проект не создаёт внешний аккаунт или базу автоматически.
4. Настройте Resend: подтвердите домен отправителя, заполните `RESEND_API_KEY`, `EMAIL_FROM`, `LEAD_NOTIFICATION_EMAIL`.
5. Выполните `npm run db:migrate` — таблицы заявок и ограничений отправки.
6. `npm run test` и `npm run build`; для собственного сервера `npm start`.
7. На Vercel добавьте переменные среды из `.env.example` в настройки проекта, затем разворачивайте обычный Next.js проект. `NEXT_PUBLIC_*` задаются до сборки.
8. Отправьте пробную заявку на своей конфигурации: проверьте таблицу `leads`, email и переход на `/thank-you`. Проверьте повторную попытку при ошибке. Доставка email и сохранение в внешнюю базу в этой сборке не проверялись: реальные ключи не были предоставлены.

Секреты нельзя добавлять в git или клиентский код. Не используйте статический export: `/api/leads` требует серверного runtime.

## Что включено

- Тёмный адаптивный дизайн, архитектурная фотография, sticky header, мобильное меню, hover/focus states и поддержка reduced motion.
- Hero, проблемы, шесть услуг, интерактивное демо Desktop/Mobile, портфолио, процесс, разработчик, форма, FAQ и финальный CTA.
- `/privacy`, `/terms`, `/thank-you`, sitemap, robots, favicon и динамическое OG-изображение.
- Canonical, Open Graph, Twitter Card, семантическая структура и Person/Organization/Service JSON-LD.
- Next/Image на основном лендинге; основные страницы рендерятся при сборке.
- React Hook Form + Zod: одинаковая схема на клиенте и сервере, обязательное согласие, условный URL, honeypot, пределы длины, защита от повторов через UUID, same-origin проверка и постоянное ограничение по email.
- Заявки хранятся в PostgreSQL с временем, согласием, версией политики, referrer и UTM. Только после сохранения сервер отвечает успехом. Если отправка email не удалась, заявка остаётся сохранённой и уведомление можно повторить.
- `npm run leads:retry` повторяет pending/failed уведомления и очищает просроченные ограничения. Можно запускать по расписанию в вашей инфраструктуре. Resend idempotency действует в пределах окна провайдера; поздний повтор может доставить повторное уведомление, но не создаёт повторную заявку.
- GA4 и LinkedIn Insight Tag опциональны и загружаются после согласия. События `page_view`, `primary_cta_click`, `portfolio_click`, `contact_form_start`, `lead_form_submit_success`, `lead_form_submit_error`, `linkedin_outbound_click`. Данные формы в аналитику не отправляются. Кампания сохраняется в рамках текущей вкладки.

## Контент и ограничения

NORTHLINE — явно подписанное демо, его форма не сохраняет данные. Проекты портфолио показаны авторскими HTML/CSS mockup, а не выданы за скриншоты. У STANISLAV PUSH и FlipZero указаны предоставленные реальные адреса; для PainRadar ссылка не выдумана. Нет фиктивных клиентов, отзывов, результатов и офиса в США.

Профессиональная фотография Alexander не была предоставлена — используется монограмма AP. Цены и сроки не выдуманы: предлагается обсуждение проекта.

Страницы Privacy и Terms — стартовые тексты для реальной конфигурации проекта; при изменении обработки данных обновите их, укажите фактические условия хранения и поставщиков. Не указывайте email или профиль, который вам не принадлежит.

Vercel Analytics и GSAP не добавлены: для этого MVP используются минимальные CSS переходы и опциональные GA4/LinkedIn. Core Web Vitals и Lighthouse являются целями, замер на реальном размещении не выполнялся. Защита формы включает honeypot и лимит по email; для рекламного трафика настройте также ограничения запросов на вашем хостинге, при необходимости добавьте CAPTCHA.

## Проверки

`npm run test` — 7 проверок: условный URL, согласие, honeypot, длина, UTM, чужой Origin, JSON и отказ при отсутствующей конфигурации. `npm run build` — production сборка и TypeScript. Проверка в браузере в среде создания была недоступна. Перед публикацией проверьте мобильные размеры, клавиатуру, форму и внешние ссылки на вашем размещении.
